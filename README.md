# portfolio_sanj

A futuristic personal portfolio website for Sanjana Badgujar, showcasing her work as an AI/ML Engineer and Python Backend Developer.

## Overview

This portfolio is a single-page experience built with HTML, CSS, and JavaScript. It presents:

- Career journey and education timeline
- AI/ML and backend engineering projects
- Tech stack and architecture overview
- Contact details and social links
- A dark, cinematic sci-fi aesthetic with animated sections and modal project views

## Run Locally

Because the main file name includes spaces, use one of the following methods:

### Option 1: Simple local server

```bash
cd portfolio_sanj
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/index%20(2).html
```

### Option 2: Open directly

Open `index (2).html` in a browser.

## Notes

This project is a static portfolio site and does not require a build step or package installation unless you want to serve it locally using a web server.
